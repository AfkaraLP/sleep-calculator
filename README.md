# Sleep Calculator

## Oxidise your sleep schedule

A project that came out of my passion for learning rust and how different parts of the language work, and also to minimise my likeliness of sleep deprivation (people that know me will know how well that worked out)

## How to run

I highly encourage you to install nix as this makes it as easy as typing `nix run .`, verified to work on wayland linux and windows 10 and 11. however if you are not willing to use nix you can simply install the rust language tooling and then run `cargo run` and hope it builds on your machine just as smoothly as it did on mine
